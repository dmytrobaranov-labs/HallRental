# 🏢 Conference Hall Rental API

Монолітний API-застосунок на **.NET 10** для управління орендою конференц-залів, розрахунку динамічних тарифів, запобігання колізіям бронювання та ведення бізнес-аналітики й звітності. Проєкт розроблено за принципами **Clean Code**, **SOLID** та методологією **TDD (Test-Driven Development)**.

---

## 🚀 Основні можливості

* **Управління залами (CRUD):** 
  * Додавання нових залів із базовою ціною та місткістю.
  * Редагування (`PUT`) та видалення (`DELETE`) існуючих залів.
* **Інтелектуальне бронювання та захист від колізій:**
  * Перевірка зайнятості: система блокує спроби забронювати один і той самий зал на час, що перетинається з уже наявними замовленнями.
  * Валідація коректності часових інтервалів (`StartTime < EndTime`).
* **Динамічне ціноутворення (`PricingCalculator`):**
  * **Ранкові години (06:00 – 09:00):** знижка 10% (`-10%`).
  * **Пікові години (12:00 – 14:00):** націнка 15% (`+15%`).
  * **Вечірні години (18:00 – 23:00):** знижка 20% (`-20%`).
  * **Стандартні години (інший час):** базова вартість.
* **Пошук доступних залів:** Фільтрація за місткістю та вільними часовими проміжками.
* **Бізнес-аналітика та звітність:** Ендпоінт для отримання зведеної статистики (загальна кількість бронювань, сумарний дохід та найпопулярніший зал).

## 📡 Основні API Ендпоінти

| Метод | Маршрут | Опис |
| :--- | :--- | :--- |
| `POST` | `/api/v1/halls` | Додавання нового конференц-залу |
| `GET` | `/api/v1/halls` | Пошук доступних залів (фільтр за місткістю та часом) |
| `PUT` | `/api/v1/halls/{id}` | Редагування інформації про зал |
| `POST` | `/api/v1/halls/{id}/accessories` | Додавання послуги до залу |
| `DELETE` | `/api/v1/halls/{id}` | Видалення залу |
| `POST` | `/api/v1/halls/book` | Оформлення бронювання з розрахунком динамічного тарифу |
| `GET` | `/api/v1/analytics/summary` | Отримання зведеного звіту та бізнес-аналітики |

### Приклад редагування залу (`PUT /api/v1/halls/{id}`)

**Вхідні дані:** ID залу в маршруті + оновлені дані в тілі запиту (наприклад, зміна вартості оренди до 2500 грн).

> ⚠️ Список `accessories` у цьому ендпоінті передається **повністю**, а не додається — включіть у нього всі наявні послуги залу, інакше старі будуть видалені. Щоб додати лише одну послугу, не чіпаючи решту, використовуйте окремий ендпоінт нижче.

```json
{
  "name": "Зал А",
  "capacity": 50,
  "basePricePerHour": 2500,
  "accessories": [
    { "name": "Проєктор", "price": 500 }
  ]
}
```

**Вихідні дані:** підтвердження успішного оновлення.
```json
{ "message": "Дані залу успішно оновлено" }
```

### Приклад додавання послуги (`POST /api/v1/halls/{id}/accessories`)

**Вхідні дані:** ID залу в маршруті + одна послуга в тілі запиту (наприклад, додавання послуги "Звук" вартістю 700 грн). Решта послуг залу залишається незмінною; якщо послуга з такою назвою вже існує — оновлюється лише її ціна.

```json
{
  "name": "Звук",
  "price": 700
}
```

**Вихідні дані:** підтвердження успішного додавання.
```json
{ "message": "Послугу успішно додано" }
```

### Рівні доступу (RBAC):
=======
## 🔒 Безпека та авторизація
* **Безпека передачі даних:** Увесь трафік примусово шифрується та перенаправляється через HTTPS (`app.UseHttpsRedirection()`).
* **Автентифікація та Авторизація:** Використання JWT-токенів для ідентифікації користувачів.
* **Рольова модель (RBAC):** 
  * Звичайні користувачі можуть шукати вільні зали та створювати бронювання.
  * Адміністратори (`AdminOnly`) мають ексклюзивні права на управління залами (CRUD) та перегляд звітності й аналітики.
* **Глобальна обробка винятків та валідація:** Захист від передачі некоректних даних та безпечні JSON-відповіді без витоку технічного стека помилок.

---

## 🔒 Безпека, ролі та тестові токени

Проєкт реалізує захист передачі даних за допомогою **HTTPS**, глобальну обробку помилок та багаторівневу авторизацію (**RBAC**) на основі **JWT**.

### Рівні доступу:
* **Публічний доступ:** Перегляд та пошук доступних залів (`GET /api/v1/halls`).
* **Зареєстровані користувачі (`User`):** Оформлення бронювань (`POST /api/v1/halls/book`).
* **Адміністратори (`AdminOnly`):** Додавання/видалення залів (`POST/DELETE /api/v1/halls`) та перегляд звітності й аналітики (`GET /api/v1/analytics/summary`).
